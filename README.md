# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация и карта;
- `order.html` — оформление заказа;
- `product1.html` — информация о товаре 1;
- `product2.html` — информация о товаре 2;
- `product3.html` — информация о товаре 3;
- `css/style.css` — основные стили;
- `css/responsive.css` — адаптивные стили (Mobile First, медиазапросы);
- `js/main.js` — файл JavaScript (модальное окно, валидация формы);
- `images/` — папка для изображений;
- `sitemap.xml` — карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Дополнительные элементы

- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок.

## Используемые технологии

- HTML5 (семантическая разметка, `<picture>`, `<dialog>`, `<iframe>`);
- CSS3 (переменные, Flexbox, Grid, `scroll-snap`, `clamp()`, `aspect-ratio`, `object-fit`);
- адаптивная вёрстка Mobile First;
- встроенная карта Яндекс.Карт;
- Git;
- GitHub;
- GitHub Pages.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- фиксирование кнопок `z-index`;
- кнопка «Наверх» `:fixed`;
- бейдж «Новинка» `:absolute`;
- карточка товара как контейнер `:relative`;
- структурированный файл `css/style.css`.
- прямые углы (`border-radius: 0`) у кнопок, карточек и бейджей — стилистика в духе BMW;
- полноэкранный hero-блок (`min-height: 100svh`) с картинкой `object-fit: cover` на всю ширину без боковых отступов;
- прозрачная шапка поверх hero (`position: absolute`) и её «твёрдый» вариант `.site-header--solid` для внутренних страниц;
- галерея изображений на странице товара через `overflow-x: auto` и `scroll-snap-type` (без JS);
- встроенная карта (`<iframe>` Яндекс.Карт) в блоке `.map-wrapper`;
- бейдж «Новинка» на красном фоне через переменную `--color-danger`;
- единая типографика: заголовки весом 500–600 без отрицательного `letter-spacing`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## Доступность и адаптивность

- семантическая разметка (`header`, `main`, `nav`, `section`, `article`, `aside`, `footer`);
- атрибуты `aria-label`, `aria-labelledby`, `aria-invalid`;
- видимый фокус `:focus-visible` у ссылок, кнопок и полей формы;
- skip-link «Перейти к основному содержимому»;
- альтернативный текст у всех изображений;
- адаптивные размеры текста через `clamp()`;
- медиазапросы в `responsive.css` для 640, 768, 900, 1024 и 1280 px;
- на странице товара галерея прокручивается горизонтально на мобильных и вертикально на десктопе.
